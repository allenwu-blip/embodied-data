# v0.2 Design Doc — Real-AgiBot Beta/Alpha forward conversion

**Goal**: replace v0.1.1's "detect-and-refuse" guard with a real forward
converter for the Beta layout. This unblocks four deferred bugs from
`docs/v0.1.1-findings.md`: #3 (14-joint), #5 (int64 ns timestamps), #9 (extra
state subgroups + sparse index companions), #10 (variable-length `*/index`
mapping).

**Non-goals for v0.2**:
- Reverse conversion (`lerobot-v3 → agibot-beta`) — single-episode reverse from
  v0.1 stays sim-only; multi-episode reverse is itself v0.3.
- Video re-encoding from Beta — Beta sample ships no `.mp4`; we can't ship a
  fully-validated video path until Allen pulls a Beta-with-video task tar
  separately. v0.2 PR ships proprio + task metadata only.
- Cross-embodiment retargeting (different robot models with non-overlapping
  joint sets).

## 1. Schema knowns (from `docs/v0.1.1-findings.md`)

Beta sample @ `data/agibot_beta_sample/675/936938/proprio_stats.h5`:

| Field | Beta value | Action in v0.2 |
| --- | --- | --- |
| filename | `proprio_stats.h5` (no second `s`) | already accepted via `_agibot_paths.PROPRIO_GLOB` |
| `state/joint/position` | `(N, 14)` float64, no `attrs.name` | new joint name list (see §2) |
| `state/end/{position,orientation,wrench}` | `(N,2,3)/(N,2,4)/(N,12)` float64 | flatten into `observation.state.end_pose` (32-dim) — optional v0.2.1 |
| `state/effector/position` | `(N, 2)` float64 (mm gripper width) | append to `observation.state` (so Beta vector dim = 14+2=16) |
| `state/head/position`, `state/waist/position` | `(N, 2)` each | append → 16+2+2 = 20-dim |
| `state/robot/{position,orientation}` | `(N,3) / (N,4)` | drop in v0.2 (mobile-base, out of scope) |
| `action/*/index` | sparse `(K,)` arrays where K ≤ N | drop in v0.2 (LeRobot v3 has no slot; carry as `auxiliary.*.mask` in v0.3) |
| `action/*/{position,velocity,...}` | matches state in shape | use first-difference recipe like sim |
| `/timestamp` | `int64` ns Unix epoch | divide by 1e9 → `float64` seconds; recompute `frame_index/fps` for output (LeRobot v3 invariant) |
| `task_info_<task>.json` | list of 399 dicts at task root | resolve target episode by `episode_id` (already handled in patch 3/6) |

**FPS**: Beta sample is ~30 Hz (1090 frames over 36.3 s). Confirm per task.

## 2. Joint-name decision

Beta `state/joint.attrs["name"]` is **missing entirely**. The 14 joints are
likely 7-DoF arm × 2 (left + right). Without an authoritative URDF dump, v0.2
options:

- **Option A**: assume canonical ordering `[arm_l_j1..7, arm_r_j1..7]` and
  ship a `JOINT_14_BETA` constant. Document the assumption in
  `docs/schema-agibot-beta.md`. Flag for upstream review.
- **Option B**: refuse if `attrs.name` missing, require user to supply via
  `--joint-names <file.json>` flag.

**Recommend Option A** for v0.2 — gives a working default + lets users
override later. Option B can come in v0.2.1 if upstream URDF reveals our
guess is wrong.

## 3. Output schema (LeRobot v3 features for Beta)

Forward writes a v3 dataset with these features (single-episode v0.2 PR):

```jsonc
"observation.state": {
  "dtype": "float32",
  "shape": [20],  // 14 joint + 2 effector + 2 head + 2 waist
  "names": ["arm_l_j1", ..., "arm_r_j7", "eff_l_w", "eff_r_w",
            "head_yaw", "head_pitch", "waist_yaw", "waist_pitch"]
},
"action": {
  "dtype": "float32", "shape": [20], "names": [<same>]
}
// videos/observation.images.* — DEFERRED until Beta sample has video
```

`action` is first-difference of state for v0.2 (matches v0.1 forward recipe).
If Beta's raw `action/joint/position` differs from state (sim had them
identical), we re-evaluate.

## 4. CLI surface change

**No new flags for v0.2** (preserves v0.1 CLI contract). The existing
`embodied-data convert <src> <dst> --from agibot --to lerobot-v3` auto-detects
sim vs Beta layout via `_agibot_paths` and routes to the correct converter.

Internal split:
- `src/embodied_data/convert/agibot_sim_to_lerobot.py` (rename of current
  `agibot_to_lerobot.py`) — DigitalWorld pipeline.
- `src/embodied_data/convert/agibot_beta_to_lerobot.py` (NEW) — Beta pipeline.
- `src/embodied_data/convert/agibot_to_lerobot.py` becomes a thin router that
  dispatches based on schema detection.

## 7. Risk & mitigations

- **Joint-name guess wrong**: `JOINT_14_BETA` is a best guess. Mitigate by
  documenting the assumption + adding `--joint-names <file.json>` override
  in v0.2.1 if any user reports their Beta task has different ordering.
- **Beta `attrs` may differ across tasks**: tested only against task 675
  episode 936938. Other tasks may have different state subgroups. Add a
  schema sanity-check at convert time that warns on unknown subgroups.
- **`action/joint/position` may not equal state in real Beta**: sim's
  identity made first-diff necessary. Beta's commanded vs realized may
  actually differ. Validate empirically; if `action == state`, keep
  first-diff; otherwise carry raw action.
