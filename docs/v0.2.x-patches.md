## [0.2.1?] task name resolution falls back to "unknown" when src is a single-episode subdir

**Symptom**

```bash
embodied-data convert \
    data/agibot_beta_sample/675/936938 \
    /tmp/beta_v3 \
    --from agibot --to lerobot-v3
```

succeeds but the resulting `meta/tasks.parquet` shows `task = "unknown"`
instead of the actual task name (e.g., `"Insert the straw"` for Beta task
675).

**Root cause**

`embodied_data.convert.agibot_beta_to_lerobot._resolve_beta_task_name(src)`
only checks `src` and `src.parent` for `task_info_*.json`. For a single-
episode src like `<root>/<task>/<ep_id>/`, the canonical Beta `task_info`
file lives at `<root>/task_info_<task>.json` — i.e., `src.parent.parent`,
which the current logic does not walk.

The batch path is unaffected because `_discover_beta_episodes` resolves
each episode's `task_info_path` against the batch root explicitly.

**Proposed fix**

Walk up from `src` until either `task_info_<task>.json` (where `<task>` is
the parent dir name) is found *or* we hit the filesystem root. Cap the walk
at 4 levels to avoid runaway searches.

```python
# in _resolve_beta_task_name
task_id = src.parent.name  # e.g. '675' if src is .../675/<ep>
for ancestor in (src, src.parent, *src.parent.parents[:3]):
    candidates = [
        ancestor / f"task_info_{task_id}.json",
        *ancestor.glob("task_info_*.json"),
    ]
    for c in candidates:
        if c.is_file():
            ...
```

**Test to add**

Single-episode CLI run pointed at `data/agibot_beta_sample/675/936938/`
should produce `meta/tasks.parquet` with `task != "unknown"`. The Beta
batch CLI test already covers the batch path correctly (it points at the
batch root).

**Severity**

LOW. Affects single-episode CLI invocations on Beta layouts only — batch
mode (`--max-episodes` or task root) is unaffected. Task name resolution
is cosmetic in `meta/tasks.parquet`; downstream training code doesn't
read it. But it's a credibility cut for the v0.2 release notes' Try-it
quick-start (which uses single-episode form), so worth a v0.2.1 ship.
